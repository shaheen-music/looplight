# Looplight

Endless music in five moods: Cozy, Sunroom, Night Drive, Jazz Noir and Scarlet Mist. Cozy, Sunroom and Night Drive (two flavours: C minor, D minor) are generated as you listen; Jazz Noir and Scarlet Mist play recordings (Scarlet Mist falls back to its generated guzheng, flute and erhu if the recordings are missing). One page, no build step, works offline once opened.

Open it here: https://shaheen-music.github.io/looplight/
